# Game Boy — C++ & SFML
A collection of 3 classic games built in C++ using SFML, developed as an Object-Oriented Programming semester project.

## Games
- **Snake** — Classic snake game with growing body and food mechanics
- **Hangman** — Word guessing game with visual hangman display
- **Wordle** — Guess the hidden word with color-coded feedback

## Tech Stack
- C++ (OOP)
- SFML 2.x — Graphics, Audio, Window
- Visual Studio

## How to Run
1. Clone the repo
2. Open `OOP_GAMEBOY.sln` in Visual Studio
3. Build and run in Debug or Release mode

> SFML headers and libraries are included in the repo.
